# 🛒 FreshMart – Retail Sales & Profitability Analysis Dashboard

> **Interactive Retail Sales & Profitability Analysis Dashboard using Microsoft Excel**

![FreshMart Dashboard](freshmart dashboard image.png)

## 🎯 Objective

To analyze **FreshMart retail sales data** and develop an interactive dashboard that provides meaningful insights into **Sales, Profit, Profit Margin, Cost, Orders, Quantity, Regional Performance, Product Categories, Store Performance, Discounts, Returns, Customer Membership, Sales Channels, Payment Methods, and Order Time**.

The main objective is to identify business performance trends, evaluate retail profitability, understand customer purchasing behavior, and support data-driven business decisions.

## 📁 Workbook Structure

The project contains 9 worksheets:

| **Worksheet** | **Description** |
|---|---|
| Supplier | Supplier master information |
| Store | Store details and regional information |
| Products | Product and category information |
| Employee | Employee master information |
| Customer | Customer details and membership information |
| Sales Sheet | Retail transaction-level sales data |
| Calculations | KPI calculations and supporting formulas |
| Dashboard | Interactive retail analytics dashboard |

## 🚀 How to Use

1. Download the FreshMart Excel workbook.
2. Open the workbook using Microsoft Excel.
3. Explore the individual worksheets to understand the source data.
4. Review the Sales Sheet for transaction-level information.
5. Open the Calculations sheet to understand KPI formulas.
6. Navigate to the Dashboard sheet to explore the visualizations.
7. Use the interactive region slicer to filter the dashboard.
8. Refresh PivotTables and PivotCharts when the source data is updated.
